# 定位.md

## 一、编号体系

| 写法 | 含义 | 例 |
|---|---|---|
| `hw1` … `hw3` | 书面作业，文件名即编号 | `hw1` = 书面作业 1 |
| `hwcode1` … `hwcode3` | 程序作业，文件名即编号 | `hwcode3` = 程序作业 3 |
| `hw1.3` | 书面作业 1 的第 3 题 | 点积记法，不用 `hw1-3` 或 `hw1 Q3` |
| `hw3.2(1)` | 第 2 题的第 (1) 小问 | 小问用全角括号 |
| `P2D` / `W2D` / `M2D` | 作业原文自带的三个问题标签（2D 边值/变分/极小化） | 原样保留，不改写 |
| `(P2D)` 等 | 原文右对齐的方程编号 | 引用时带括号 |

- 作业内**没有章节号**，因此溯源行一律写「`hw3.pdf` 第 1 页 第 2 题」，不写「§x.y」。
- 教材溯源行写「`Brenner` §5.2（印刷页 132 / PDF 第 146 页）」。

## 二、页码口径（PDF 页序 ≠ 印刷页，必须换算）

实测锚点，换算公式 `PDF 页 = 印刷页 + 偏移`：

| 书 | 偏移 | 锚点证据 |
|---|---|---|
| Johnson | **+0** | PDF 第 10 页页脚印「10」，正文即 §0.2 |
| Brenner & Scott | **+14** | PDF 第 15 页为 Chapter 0，印刷页 1 |
| Boffi–Brezzi–Fortin | **+15** | PDF 第 16 页为 Chapter 1，页脚「1」 |
| Ciarlet | **+29** | PDF 第 30 页为 CHAPTER 1，印刷页 1 |
| A Multigrid Tutorial | **+13** | PDF 第 14 页为 Chapter 1；PDF 第 20 页页脚「7」 |

- 各书自带的 TOC 用的是**印刷页**；写「翻到 PDF 第几页」时必须自行加偏移。
- Johnson 全书扫描、无书签目录，章页只能靠渲染读图确认，偏移恰为 0 属巧合（前附页被裁掉）。

**写法约定**：

- 弱形式统一写 $a(u,v)=(f,v)\ \ \forall v\in V$，不写 $a(u,v)=l(v)$（作业用 $(f,v)$）。
- 强形式统一写 $-u''+u=f$、$-\Delta u=f$，系数不省略。
- 边界条件写成并列两行 $u(0)=u(1)=0$，与作业排版一致。
- 有限元解写 $u_h$（作业用 $u_h$），试探函数写 $v_h$。
