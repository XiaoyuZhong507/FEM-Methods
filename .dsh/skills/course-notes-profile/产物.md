## 二、`整理/教材与作业整理.md` 的固定骨架

1. 三行前置说明：资料来源 / 覆盖范围 / 整理原则
2. 资料清单（现场扫描结果，含页数、文本层状况）
3. 教材地图：五本书的四级定位（主推 / 参考 / 进阶 / 拓展）+ 章节主题 + 页码偏移
4. 课程知识主线：由作业反推的 B1–B6 块，每块给「考什么 → 在哪本书哪一节」
5. 作业台账：编号、类型、题量、布置/提交状态、内容摘要
6. 作业逐题转录 + 考查点 + 教材定位 + 解题要点
7. 疑点与勘误（引用 `取舍.md` 的 E-01…E-05）
8. 附录 A 公式速查 / B 概念辨析 / C 题型模板 / D 勘误
9. 末尾一行 `> **下一步建议**：…`

写这份文档时的硬约束：

- **题干必须来自渲染图核对**，不得用 PDF 文本层（公式全被压坏）。
- 每道题都要能追到至少一本教材的具体小节，追不到就写「教材无直接对应，属课堂内容，待补充讲义」。
- 不写整本教材的内容摘要；一本书最多给到「章 → 主题 → 与哪个块相关」的粒度。

## 三、学习进度文档：尚未建立的说明

`整理/学习进度.md` **不存在**，且不得凭「我学到第几章」直接生成。初始化必须走 A 层 §11.2 的三轮访谈：

1. 第 1 轮客观边界（老师讲到哪、已讲章清单、作业布置到哪、下次课内容）
2. 第 2 轮掌握度自评（按已讲块，五档图例）
3. 第 3 轮知识检验（从已讲范围 + 本目录资料源出 3–5 题）

在此之前，一切「进度」表述只能写「待确认」。
