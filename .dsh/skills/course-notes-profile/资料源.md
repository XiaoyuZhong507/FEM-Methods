## 三、读取限制（踩过的坑）

1. **`johnson_FEM.pdf` 是扫描件，`get_text()` 返回空**。任何引用都要先渲染成图再读：`page.get_pixmap(dpi=110~140)` + 读图。不要因为“提取不到文字”判定文件损坏。
2. **作业 PDF 的文本层把公式压坏了**：`∫` 变 `Z`、上下限跑到下一行、`\sum` 直接丢。**公式必须以渲染图核对**，不能拿文本层当题干。
3. **Ciarlet 的文本层有编码乱码**：`§` 显示为 `��`（如 `[Ch. 1, �� 1.1.]`），`^` 显示为 `^`。按上下文还原即可，不影响阅读。
4. 中文路径在 PowerShell 里读写正常，但 Python 的 `print` 走 GBK 会崩：**先写 UTF-8 文件再用 `Get-Content -Encoding utf8` 看**。

## 四、清单刷新命令

```powershell
Get-ChildItem -Recurse -File 教材,作业 | ForEach-Object { "{0,9} {1}" -f $_.Length, $_.FullName }
```

需要页数/文本层/目录时（pymupdf 1.27.2 已装，python 3.11）：

```powershell
python -c "import fitz,glob;[print(p, fitz.open(p).page_count) for p in glob.glob('教材/**/*.pdf',recursive=True)]"
```
