## 四、读取限制（逐条都是踩过的坑）

1. **`johnson_FEM.pdf` 是扫描件**，`get_text()` 全空 → 必须渲染成图再读（dpi 110–140）。Johnson 的页码 PDF = 印刷页。
2. **作业 PDF 的文本层把公式压坏**：`∫` 变 `Z`、上下限跑到行尾、`\sum` 丢失 → 公式一律按渲染图核对。
3. **docx 里的公式是 OMML，`python-docx` 的 `paragraph.text` 读不到**，只能拿到文字骨架（会出现「取。设是的解」这种断句）。要完整公式请读同名 PDF 答卷，或把 docx 导出 PDF。**不要因此判定文件损坏。**
4. **Word 锁文件 `~$xxx.docx` 要跳过**，否则 `docx.Document()` 抛 `PackageNotFoundError`（`作业4/` 里就有一个，说明该 docx 正在 Word 中打开）。
5. **Ciarlet 文本层有编码乱码**：`§` 显示为 `��`。
6. 中文路径 + Python `print` 走 GBK 会崩：先写 UTF-8 文件，再用 `Get-Content -Encoding utf8` 看。

## 五、清单刷新命令

```powershell
Get-ChildItem -Recurse -File 教材,作业 | ForEach-Object { "{0,9} {1}" -f $_.Length, $_.FullName }
```

批量读 docx 文字（跳过锁文件）：

```powershell
python -c "import glob,docx,os;[print('=====',p,'\n','\n'.join(t.text for t in docx.Document(p).paragraphs if t.text.strip())[:2000]) for p in glob.glob('作业/有限元作业1-5/*/*.docx') if not os.path.basename(p).startswith('~$')]"
```
