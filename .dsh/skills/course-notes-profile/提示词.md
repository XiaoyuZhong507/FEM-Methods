# 提示词.md

> 格式见 A 层 §12.2：场景 / 变量 / 提示词原文 / 备注。编号 `P-NN` 只增不改，废弃留删除线。
> **规则**：用户给的提示词原样照抄，不改写；下面的条目均为生成时拟定的**示例**，待用户确认或替换。

### P-01 作业逐题解答（书面）
- **场景**：要求解 `hwN.pdf` 里的某一题，且需要「先答案后步骤 + 回代检验」的完整版
- **变量**：`{作业号}`、`{题号}`、`{教材名}`
- **提示词**：
  ```
  按 course-helper 的 A 层 §7 解答 {作业号} 第 {题号} 题：先给结论，再给考查点、完整推导、回代检验；中间步骤不许省略，不许写「显然」。溯源到 {教材名} 的具体小节。
  ```
- **备注**：题干必须从渲染图读，不信 PDF 文本层（见 `资料源.md` §三）。

### P-02 程序作业的实现与误差表
- **场景**：hwcode1 / hwcode3 这类要求「组装 + 误差 + 收敛阶表」的作业
- **变量**：`{作业号}`、`{边界条件类型}`、`{N 取值}`
- **提示词**：
  ```
  实现 {作业号}：等距网格、P1 单元、{边界条件类型}。输出 N={N 取值} 的 L2/H1 误差与 Ord 表，说明每列的理论阶并解释实测值偏离的原因。
  ```
- **备注**：纯 Neumann 必须先处理刚度矩阵奇异（`取舍.md` E-04），否则阶数会失真。

### P-03 资料源刷新
- **场景**：新学期又发了新的 PDF，需要确认档案是否过期
- **变量**：无
- **提示词**：
  ```
  按 .dsh/skills/course-notes-profile/资料源.md 的刷新命令重扫教材与作业目录，只报告新增/删除的文件及其页数与文本层状况，不要重写档案其余部分。
  ```
- **备注**：只重扫，不改 `资料源.md` 之外的模块。
